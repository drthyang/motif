# Example structures

Published structures from the Crystallography Open Database (COD, https://www.crystallography.net/cod/),
which places its data in the public domain. Each file keeps its COD header with the original reference.

| File | Structure | COD entry |
|------|-----------|-----------|
| `silicon_COD-9008565.cif` | silicon, diamond structure | 9008565 |
| `halite-NaCl_COD-9008678.cif` | rock salt | 9008678 |
| `perovskite-SrTiO3_COD-9006864.cif` | cubic perovskite (tausonite) | 9006864 |
| `quartz_COD-9009666.cif` | quartz, hexagonal axes | 9009666 |
| `olivine-FeMg_COD-1541262.cif` | olivine with two sites shared by Fe and Mg | 1541262 |
